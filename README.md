# New Hampshire Legislature 2026 Forecast

A probabilistic forecast of the November 3, 2026 elections for all 24 New Hampshire State Senate seats and all 400
State House seats, in the style of the Pennsylvania Legislature forecast it was adapted from. Public data only;
every weight lives in one config file; every input to every district is shown on that district's page.

- **Live site:** https://alainxc.github.io/nh-legislature-2026-forecast/
- **Site files:** `site/` (static HTML; deployed to GitHub Pages from the zip in the repository root)
- **Model config:** `config/model_config.yaml`; regions in `config/regions.yaml`
- **Methodology:** `docs/methodology.md` (rendered at `site/methodology.html`)
- **Sources and audit:** `docs/sources.md` (generated from `data/raw/*/MANIFEST.json`), `docs/DATA_AUDIT.md`
- **Data notes:** `NH_DATA_NOTES.md` and each `data/raw/<topic>/NOTES.md`

## Update routine

```bash
./run.sh              # refresh sources that can be refreshed, process, forecast (40,000 sims), backtest, build, zip
./run.sh --publish    # ...and upload the zip to GitHub, which redeploys the site
./run.sh --no-fetch   # use the raw captures already on disk
```

First-time setup: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`, and `gh auth login` once for publishing.

## What is New Hampshire-specific

- Town and city-ward level returns (OpenElections' transcription of the Secretary of State tabulations) are
  aggregated to districts using RSA 662:3 and 662:5, so baselines are exact, including for floterial districts.
- The House is simulated at the candidate level: each candidate's share is the party share plus an incumbency bonus
  plus a candidate deviation estimated from 2022/2024 within-district spreads; the top k win. Short slates lose
  seats mechanically.
- The statewide environment combines the one legislative generic-ballot poll with the governor's race (personal
  vote removed), NH-01/NH-02, the statewide congressional preference and the national generic ballot, then applies
  a legislative-vs-top-of-ticket offset estimated from 2022 and 2024.

## Layout

```
config/            model_config.yaml, regions.yaml
pipeline/fetch/    build_districts (statutes), build_results (returns), build_baseline, build_candidates,
                   build_polls, build_geo, fetch_sources, write_manifest, nh_names
pipeline/          model.py, simulate.py, run_forecast.py, backtest.py, build_site.py, sources_doc.py, changelog_entry.py
templates/         Jinja2 templates
site/              the published site (generated; assets/ kept)
data/raw/          untouched captures + MANIFEST.json + NOTES.md per topic
data/processed/    model-ready CSVs, all generated by the pipeline
output/            forecast.json, senate_seats.csv, house_districts.csv, backtest.json
```
